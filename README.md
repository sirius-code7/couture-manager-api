
# couture manager api

api rest de gestion d'un atelier de couture, développée avec python et fastapi.

## objectif

centraliser la gestion des clients, des mesures, des commandes, des paiements et des livraisons d'un atelier de couture.

## technologies

- python 3.12
- fastAPI
- postgreSQL
- SQLAlchemy 2
- pydantic
- alembic
- pytest
- docker
